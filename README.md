# RaBbLE-sCoRE

The coordination engine of the [RaBbLE Collective](https://joinrabble.world): intent in, decompose,
delegate, result out. sCoRE is the first iteration of RaBbLE itself: a FastAPI server that holds
RaBbLE's persona, routes across LLM providers, and serves the chat and the Pocket's voice beam.
